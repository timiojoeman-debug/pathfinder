# Glossary

Cross-domain terms used throughout PathFinder. Each links to the concept guide and the structured concept id in the [knowledge model](../src/lib/knowledge/).

| Term | One-line meaning | Concept id |
|------|------------------|------------|
| **Hidden job market** | The 70–80% of roles filled before any public posting. | `c-hidden-job-market` |
| **Referral leverage** | A warm referral converts ~6–10× better than a cold application. | `c-referral-leverage` |
| **Coffee chat** | A 20–30 min informal conversation to build rapport, not ask for a job. | `c-coffee-chat` |
| **Four Pillars** | Brand · applications · networking · interview prep — the diagnostic model of a search. | `c-four-pillars` |
| **Apply early** | Applying in the first 48–72h of a posting can 3–5× callbacks. | `c-apply-early` |
| **AI screening reality** | ~85% of companies auto-screen; generic volume gets filtered. | `c-ai-screening` |
| **Application funnel** | The conversion math: ~80–120 tailored roles → 1–4 offers. | `c-application-funnel` |
| **Proof of work** | The 2026 bar is fit + demonstrable evidence; show, don't tell. | `c-proof-of-work` |
| **Quantified impact** | Achievements not duties: action verb + task + result, ≥2 metrics/role. | `c-quantified-impact` |
| **ATS optimisation** | Surviving the AI filter + 6–8s recruiter scan. | `c-ats-optimization` |
| **STARL** | Situation · Task · Action · Result · **Learnings** — behavioural-answer framework. | `c-starl` *(planned)* |
| **Hiring pyramid** | The four tiers hires come from: internal → manager's network → referrals → cold. | framework `f-hiring-pyramid` |

Terms marked *(planned)* exist in the Obsidian vault and source registry but are not yet built into the structured knowledge layer — they are the next domains to slice. The **networking**, **jobs**, and **cv** domains are fully built. See [knowledge_health.md](../knowledge_health.md).
